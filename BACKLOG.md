## 2. Инженер по источникам
- [x] Коннектор RSS/сайтов: нативные фиды TAdviser/НИУ ВШЭ, универсальный CSS-скрапер
      для ICT.Moscow, получение полного HTML и общий extractor HTML/PDF/DOCX. Контракты
      и preset-настройки покрыты fixtures-тестами; живой ICT.Moscow не ответил из среды
      разработки, поэтому селекторы перепроверить в первом production-прогоне.
- [x] Коннектор Telegram-каналов: RSS-Bridge и веб-превью `t.me/s/<канал>` (то же,
      что использует RSS-Bridge) — подтверждено для обычных каналов (@ailev_blog
      отдаёт полный текст постов). Транспорты выбираются явно через `collector`, без
      тихого fallback. Для каналов, где веб-превью не отдаёт посты вообще (см. ниже
      про @expertosphere), — сразу Telethon, не как запасной вариант.
- [x] @expertosphere — особый случай: веб-превью не отдаёт посты вообще (проверено
      31.08.2026), плюс сами отчёты лежат вложенными файлами, а RSS-Bridge в любом случае
      отдал бы только имя и размер файла, не содержимое (проверено по исходнику бриджа) —
      реализован Telethon: скачать документ + извлечь текст PDF/DOCX; PDF-скан без
      текстового слоя возвращает типизированную ошибку (OCR отложен).
- [x] Приведение всех типов к строгому общему `RawItem`/`Attachment` и
      `CollectionBatch`: заголовок/сырой текст или HTML, оригинальная ссылка, UTC-дата,
      источник, стабильный external id, вложения, metadata, cursor и типизированные ошибки.

день, или тишина, если по теме ничего не нашлось, без ручного запуска.
